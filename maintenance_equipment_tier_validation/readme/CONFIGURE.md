To configure this module, you need to:

1. Go to Settings \> Technical \> Tier Validations \> Tier Definition.
2. Create as many tiers as you want for the Maintenance Equipment model.

Once an equipment is validated, its fields become read-only. To keep some fields
editable on confirmed equipment (e.g. location, technician, note):

1. Go to Settings \> Technical \> Tier Validations \> Tier Validation Exception.
2. Create an exception for the Maintenance Equipment model, select those fields and
   check "Write after Validation".

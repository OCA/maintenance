From Maintenance Requests
1. Navigate to **Maintenance > Maintenance Requests**
2. Open an existing maintenance request or create a new one
3. In the maintenance request form, you'll find a tab for **Helpdesk Tickets**
4. Use this tab to link one or more helpdesk tickets to the maintenance request
5. Select existing tickets or create new ones directly from this interface

From Helpdesk Tickets
1. Navigate to **Helpdesk > Tickets**
2. Open a helpdesk ticket
3. If the ticket is linked to maintenance requests, you'll see a **Maintenance** smart button in the top-right area
4. Click the smart button to view all linked maintenance requests
5. The button shows the count of associated maintenance requests
